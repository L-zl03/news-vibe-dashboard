# AI 智能情报与立场博弈看板 · 编辑工作台

保留原有主题检索与多方立场分析，增加事实卡片、选题建议、采访清单及编辑核查记录。入口仍为 `dashboard.py`。

## 本地运行

界面采用黑白灰原生主题，字体与配色位于 `.streamlit/config.toml`。标题使用自托管的 **Ink Editorial Light**（基于霞鹜文楷轻体的 GB 2312 网页子集，OFL 授权），营造清瘦书法笔意；并非真正的瘦金体字库。正文使用易读的系统衬线字体。首页远山为项目内原创 SVG，字体与插图均不依赖外部 CDN。请一并部署 `assets/`、`static/fonts/` 和 `.streamlit/config.toml`；首次增加字体配置后需重启服务。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/streamlit run dashboard.py
```

真实模式需要在 `.streamlit/secrets.toml` 或 Streamlit Community Cloud 的 Secrets 中配置：

```toml
TAVILY_API_KEY = "替换为搜索服务密钥"
# 可选；不设置时由用户在侧栏填写。
DEEPSEEK_API_KEY = "替换为模型密钥"
# 可选，默认延用原项目模型名称。
DEEPSEEK_MODEL = "deepseek-chat"
```

无密钥时可主动选择“体验虚构样例”。样例是固定的虚构公交议题，不会套用用户主题、搜索或调用模型。真实模式失败不会自动降级成演示报告，不会将知识库推测充当最新新闻。

## 功能与核验边界

- **事实卡片**：具体主张、当事方、主张类型、支持/反驳/背景材料、逐字摘录、来源日期和抓取时间、尚缺证据。
- **摘录校验**：对 source ID 和连续文本做本地匹配（忽略空白）。不匹配的证据移除并显示提示；这不等于语义核验或判定事实真实。
- **正文与摘要**：Tavily 返回正文时优先取正文；否则明确标记“检索摘要”。每份材料最多提供前 10,000 字符，因此可能遗漏后半部分。
- **来源日期**：只读取服务返回的 published_date 元数据，不从网址、抓取时间或模型输出猜测。服务不提供日期时标为“未提供”。日期仍需回原文确认。
- **交叉验证**：多个材料默认只显示“独立性待人工核查”。必须由编辑回原文确认独立采集、勾选并填写依据，才显示“编辑已确认”。同一公告的转载不算独立采集。系统不会自动识别所有同源转载。
- **选题建议**：为什么现在写、本轮材料缺口、适合读者、切入角度与事实编号。不宣称某个角度全网尚无人报道。关联证据无近七日有效日期时，强制提示尚无已核实的今日新闻钩子。
- **采访清单**：对象角色、具体问题、待取得材料、优先级与事实编号。不自动联系任何人。
- **立场分析**：标注直接表态、报道概括或分析推断；标注本身由模型生成，仍需人工核对。该模块独立校验：兼容单条对象与单个事实编号，非标准归因标签保守标为“分析推断”；缺少观点或有效事实引用的立场跳过并提示。不会因为立场格式异常丢弃其他有效模块，也不会补造立场或证据编号。
- **导出**：先“准备下载”生成包含当前编辑核查记录的快照，再下载 Markdown；结果不会因下载消失。改变核查记录后应重新准备快照。

主题、地域与时间范围相同的公开搜索材料在当前会话缓存十分钟；不缓存或保存 API 密钥。不在错误提示中回显第三方 SDK 异常。会话状态不是永久存储，关页或服务重启可能丢失核查记录。

生成前会检查侧栏或云端的密钥配置，清理首尾空白及包裹引号。内部出现非 ASCII 字符、空白或控制字符时，明确提示修改位置，不发起搜索或模型请求。此检查不限制中文选题，也不代表密钥已通过服务端认证。其他编码错误与网络错误分别提示，均不回显密钥内容。

原先的无依据雷达评分已替换为材料数、事实卡片数、缺失日期数，避免对不同议题套用科技资本指标。原“思考链”改为简短的方法与局限说明。

## 验证

```sh
.venv/bin/python -m unittest discover -s tests -v
```

测试覆盖伪造摘录、非法/未知来源、错误事实编号、重复证据、交叉验证人工门槛、新闻时效、导出和会话交互。测试不调用付费 API。

## 更新原网站

将本项目文件推送到原 GitHub 仓库 `l-zl03/news-vibe-dashboard` 的部署分支后，Streamlit Community Cloud 会按现有配置重新构建。保持入口 `dashboard.py`，保留云端原有的 `TAVILY_API_KEY`。密钥仅放在 Secrets，不能提交到 Git。

本地测试与云端部署是两步；只有云端更新成功并实测后，才能称线上网站已完成更新。
