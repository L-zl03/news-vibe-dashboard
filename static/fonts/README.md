# Ink Editorial Light

Derived from [LXGW WenKai Lite Light](https://github.com/lxgw/LxgwWenKai-Lite), by LXGW and the upstream Klee contributors. Distributed under SIL Open Font License 1.1; see the accompanying `OFL.txt`.

This web edition is renamed **Ink Editorial** to respect reserved font names. It retains ASCII and GB 2312 characters from the original font and is converted to WOFF2 using fontTools. Other characters use the browser's fallback font. Original copyright and license name records remain embedded.

The lightweight calligraphic forms are used for headings only. They evoke a fine brush aesthetic; this is not a licensed reproduction of a Shoujin (瘦金体) font. The font is served by the app, without external font CDN requests.

Upstream source: `fonts/TTF/LXGWWenKaiLite-Light.ttf`, downloaded 2026-11-14. Original full font is not required at runtime.
